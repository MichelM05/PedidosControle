# src — aplicação Laravel + React

Código da aplicação (Laravel 12 no back, React + Inertia no front). A documentação completa está no
[README da raiz](../README.md) e em [`../docs`](../docs).

```bash
php artisan test         # testes (back)
vendor/bin/pint          # estilo do código PHP
npm run dev              # front com recarregamento automático
npm run build            # confere os tipos e compila o front (Vite)
npm run typecheck        # só a checagem TypeScript
npm audit                # vulnerabilidades das dependências (rode aqui, onde está o package.json)
```
